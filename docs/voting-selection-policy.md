# 民謡ABC 選曲・投票方針

## 公開企画：投票で選ぶ26曲

- 公開する投票候補は、編集部が選定した民謡100曲。
- 投票者には「本に入れたい曲」を選んでもらう。
- 集計結果をもとに、書籍の表の26曲を決める。
- 投票前に候補100曲の名称・地域・出典を確認し、候補リストを固定する。
- 投票ルール（1人あたりの選択数、投票期間、重複投票の扱い）は、公開前に明示する。
- 投票サイトは、送信先・集計方法・プライバシーの説明が整うまでは「試作」と表示する。

## 非公開企画：秘密の26曲

- 「裏の26曲」は、公開投票とは独立した編集企画として扱う。
- 投票ページには掲載しない。候補名、選定理由、進捗も公開しない。
- 公開ランキングの下位曲を自動的に裏の26曲にすることもしない。
- 編集側の非公開マスターで選曲し、表の26曲と重複しないように照合する。
- 裏の26曲は、表の人気投票とは異なる編集上の価値（地域の多様性、歌われる場面、文化的背景、資料の確かさなど）を軸に選ぶ。
- 「秘密」は選曲プロセスの演出であり、曲の由来や文化的事実を秘密扱いにする意味ではない。掲載時には出典と説明を付ける。

## 選曲データの分離

| データ | 公開範囲 | 役割 |
| --- | --- | --- |
| 公開候補100曲 | 公開 | 投票者が選ぶ候補 |
| 投票集計 | 公開範囲を別途決定 | 表の26曲の選定根拠 |
| 表の26曲 | 公開 | 人気投票を踏まえた本の中心 |
| 秘密の26曲 | 非公開 | 別枠の編集企画 |
| 出典・権利確認 | 編集チーム | すべての収録曲に必要 |
