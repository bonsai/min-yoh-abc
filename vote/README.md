# 民謡ABC 人気投票サイト（試作）

## 目的
書籍『民謡ABC』に収録する厳選26曲を決めるため、読者・参加者が候補曲を選ぶ投票UIの試作です。

## 公開先
GitHub Pages がリポジトリのルートを公開している場合、サイトは `/vote/` で表示できます。
https://bonsai.github.io/min-yoh-abc/vote/

## 現在の機能
- 民謡候補26曲の表示
- 最大5曲まで選択
- 曲名・地域検索、地域フィルター
- 選択内容をブラウザーの localStorage に保存
- モバイル対応

## 重要：集計はまだできません
現状はフロントエンドの試作です。投票内容は投票した人の端末内にしか保存されず、主催者側へ送信されません。複数人の票を集めて順位を出すには、Cloudflare Workers + D1、Supabase などの共有バックエンド、またはフォームサービスとの接続が必要です。公開投票として告知する前に、集計先と重複投票の扱いを決めて実装してください。

## 候補曲について
26曲は投票画面を作るための暫定候補です。曲名・地域表記、学校教科書への掲載状況、由来、権利・出典は編集時に個別確認してください。投票結果だけで収録曲を自動確定せず、編集方針と資料の信頼性も合わせて判断します。
