# 民謡ABC 人気投票サイト（PWA試作）

## 目的
書籍『民謡ABC』に収録する表の26曲を考えるための、スマートフォン対応・PWA対応の投票UI試作です。秘密の26曲は投票画面や公開データに含めません。

## 公開先
GitHub Pages がリポジトリのルートを公開している場合：
https://bonsai.github.io/min-yoh-abc/vote/

## PWA機能
- スマートフォンの画面幅に対応
- Web App Manifest とアイコンを設定
- Service Worker によるアプリシェルのキャッシュ
- 一度読み込んだ後のオフライン表示（ブラウザーの対応状況による）
- Android Chrome などのブラウザーからホーム画面に追加可能
- iPhone/iPad は Safari の共有メニューから「ホーム画面に追加」

## ホーム画面への追加
- **Android:** Chromeで公開URLを開き、メニューの「ホーム画面に追加」または「アプリをインストール」を選びます。
- **iPhone/iPad:** Safariで公開URLを開き、共有ボタンから「ホーム画面に追加」を選びます。
- インストールやService WorkerはHTTPSで配信された公開URLで確認してください。ローカルファイル表示では動作しません。

## 現在の機能
- 暫定候補26曲の表示
- 最大5曲まで選択
- 曲名・地域検索、地域フィルター
- 選択内容をブラウザーの localStorage に保存
- PWA用マニフェスト、アイコン、Service Worker

## 重要：共有投票の集計は未実装
現状はフロントエンドの試作です。投票内容は投票した人の端末内にしか保存されず、主催者側へ送信されません。複数人の票を集めて順位を出すには、Cloudflare Workers + D1、Supabase などの共有バックエンド、またはフォームサービスとの接続が必要です。公開投票として告知する前に、集計先と重複投票の扱いを決めて実装してください。

## 候補曲について
画面の26曲は暫定候補で、100曲の正式リストではありません。曲名・地域表記・由来・出典を個別確認してください。秘密の26曲は公開候補・投票データに含めません。
