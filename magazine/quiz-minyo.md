# 民謡クイズ（ジン用）2026-11-05

## 安来節（島根・安来）簡単クイズ5問

1. 安来節は、どこの民謡でしょう？
2. 安来節の合間に踊られる、滑稽な踊りの名前は？
3. その踊りで、鼻につけるものは何でしょう？
4. 踊るとき手に持つ、すくうための道具は？
5. 江戸時代、安来に各地の唄を運んできた船の名前は？

### 答え
1. 島根県安来市（出雲の民謡）
2. どじょうすくい踊り
3. 一文銭（鼻あて）。豆絞りの手ぬぐいを頭に、腰にはビク（魚籠）を下げる
4. ザル（竹ざる）
5. 北前船。安来は鉄と米の積出港で、船頭たちが全国の民謡を持ち込み、持ち帰った

## 安来節 むずかしクイズ5問

1. 明治の終わり、全国巡業とレコードで安来節の黄金時代を築いた「初代」と呼ばれる唄い手は誰？
2. 正調安来節保存会が設立されたのは何年？
3. どじょうすくいの所作は、実はどじょう取りではなく、ある労働の動きが元だという説があります。何の労働でしょう？
4. 安来節の原型の一つとされる、土地の唄の名前は？（天保の頃、芸妓おさんが歌ったと伝わる）
5. 安来節は2016年、ある日本遺産の構成文化財に認定されました。その日本遺産の名前は？

### 答え
1. 渡部お糸（初代）。三味線の富田徳之助（ジャバ徳）と一座を組み、全国を回った。家元は代々「渡部お糸」を襲名する
2. 1911年（明治44年）。乱れつつあった安来節の正調を守るために設立。2014年には安来市の無形民俗文化財に指定
3. 砂鉄採取。安来鋼を作るたたら製鉄の原料・砂鉄を川で集める所作が、踊りに取り込まれたという説
4. さんこ節
5. 日本遺産「出雲國たたら風土記」

## おてもやん（熊本）簡単クイズ5問

1. おてもやんは、どこの民謡でしょう？
2. 「おてもやん」の「やん」は、標準語の何にあたりますか？
3. 歌い出しで「あんたこの頃、どうしたではないかいな」と聞かれるのは何？
4. それをしたのに、まだ三々九度の杯（さかずき）をしていないのはなぜ？
5. おてもやんが、もともと呼ばれていた名前は？

### 答え
1. 熊本県（肥後）の民謡
2. 「さん」。つまり「おてもさん」
3. 嫁入り（結婚）した
4. 亭主が「ぐじゃっぺ」（熊本弁で不細工、あばた顔）だから。「嫁入りしたこつぁしたばってん、ご亭どんがぐじゃっぺだるけん、まあだ盃ゃせんだった」
5. 熊本甚句。花柳界のお座敷歌だった

## おてもやん むずかしクイズ5問

1. おてもやんを作詞・作曲（編曲）した、三味線と踊りの師匠の名前は？
2. 1936年（昭和11年）にレコードへ吹き込み、全国に広めるきっかけを作った歌手は？
3. おてもやんのモデルとされる、師匠の弟子だった女性の名前は？
4. 1907年、与謝野鉄幹・北原白秋らの紀行文に記録され、東京でも流行するきっかけになった作品の題名は？
5. 歌の後半、「男振りには惚れんばな（男の見かけには惚れないが）」のあと、おてもやんが惚れたのは何？

### 答え
1. 永田イネ（1865–1938）。「おてもやんあんたこの頃」と「一つ山越え」の2節はイネの作詞とされる
2. 赤坂小梅
3. 富永チモ（登茂）。小作農家の長女で、イネのもとに通っていた女性。ただしイネ自身はモデルを最後まで公表しなかった
4. 「五足の靴」
5. 煙草入れの銀金具。「それがそもそも因縁たい」

## 江州音頭（滋賀）簡単クイズ5問

1. 江州音頭は、どこの音頭でしょう？
2. 「江州」とは、どこの国の別称でしょう？
3. 江州音頭は、主にいつ踊られるでしょう？
4. 江州音頭を作り上げた、板前出身で「歌寅」と呼ばれた名人は誰でしょう？
5. 豊郷の千樹寺で踊るとき、踊り手に手渡された華やかな小道具2つは何でしょう？

### 答え
1. 滋賀県（近江）を中心に、近畿地方各地で盆踊りに用いられる音頭
2. 近江国
3. 夏のお盆（滋賀では8月の盆踊りとして定着。豊郷では千樹寺の観音盆）
4. 西沢寅吉。歌が好きで「歌寅」と呼ばれ、桜川雛山に習った歌祭文に歌念仏・念仏踊りを取り入れて作り上げた
5. 絵日傘と扇。今も豊郷では「絵日傘踊り」「扇踊り」として保存・継承されている

## 江州音頭 むずかしクイズ5問

1. 歌寅（西沢寅吉）が文政12年頃に師事した、武蔵国のデロレン祭文の名人は誰？
2. 歌寅が師の許しを得て名乗り、江州音頭の家元となった名前は？
3. 歌寅と協力して演目を整えた、もう一人の家元は誰？（真鍮細工が本業だった）
4. 江州音頭が初めて披露されたと伝わる、豊郷町のお寺は？
5. 江州音頭になる前、八日市で呼ばれていた直接の起源の名前は？

### 答え
1. 桜川雛山（万宝院桜川雛山）
2. 初代桜川大龍
3. 奥村久左衛門（初代真鍮家好文）。桜川派と真鍮家派の2流派が源流とされる
4. 千樹寺（日吉山千樹寺、豊郷町下枝）。発祥の地は八日市（考案の地、現・東近江市延命公園）と千樹寺の2か所とされる
5. 八日市祭文音頭（江州八日市祭文音頭）。大阪で河内音頭と並んで演じられるようになってから、区別のために「江州音頭」の呼び名が定着したとも言われる
